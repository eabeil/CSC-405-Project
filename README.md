# What Wins in the Premier League?

This project asks how Premier League champions balanced scoring and defending from 2010/11 through 2020/21, and whether recent attacking or defensive form helps predict match results before kickoff.

The 11-season dataset contains 4,180 fixtures. The report will compare champions with the rest of the league and look more closely at Leicester City in 2015/16 and Manchester City in 2017/18. The models will predict a home win, draw, or away win using information available before each match. [Football-Data.co.uk Premier League results](https://www.football-data.co.uk/englandm.php)
